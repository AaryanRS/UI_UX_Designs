# Contributing

Thanks for wanting to share your UI/UX designs with this repository!

To keep things clean and simple, please make sure your Pull Request (PR) includes only the following inside a new project folder:
- **HTML file** (`index.html` or your main markup file)
- **README file** (`README.md` with a short overview of the design)
- **Prompt file** (a `.txt` or `.md` file containing the prompt used, if applicable)
- **Design preview photo** (a `.png`, `.jpg`, or `.webp` screenshot of your design)

If I like your design, I will merge your PR and add your name to the repository as credit for your work!
